# CDC 2080

## Section A

**Attempt any two questions.**

1. Differentiate between one-pass and multi-pass compiler. Construct the LL(1) parsing table for the following grammar.

   S → ABCD

   A → a | ε

   B → b

   C → 0 | ε

   D → d | ε

2. How does Lexical Analyzer recognize a token? Give an example to make it clear. Convert the regular expression a(a+b)(b+c)\*a# to DFA.

3. Construct the LR(1) parsing table for the following grammar.

   S → AaAb

   A → BbBa

   A → ε

   B → ε
